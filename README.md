# 麗山高中生物科財產管理與盤點系統

手機直式與桌面皆可使用的離線財產清冊工具，包含動產、物品、分類統計、快速查詢、逐筆盤點、年度比對及備份還原。

## 開始使用

1. 可直接透過 GitHub Pages 使用線上版；也可下載 `生物科財產工作站.html` 以瀏覽器離線開啟。
2. 盤點前點「立即儲存」或下載完整工作檔；瀏覽器資料各裝置分開保存，不會自動同步。
3. 換裝置時，在原裝置下載「完整工作檔」，再於新裝置還原。
4. 手機直式操作與故障排除見 [使用說明](使用說明.md)。

## 資料範圍

目前版本預載 115 年度生物科動產與物品清冊（821 筆），並在單一 HTML 中內嵌對應原始 PDF，以便按原始頁碼查核。後續年度可匯入 CSV、JSON 或 PDF。

盤點備註、勾選、手動新增與位置修訂留在使用者瀏覽器／匯出的工作檔，不會由此 GitHub 專案同步收集。Google 圖片搜尋只有在使用者點擊後才會開啟外部搜尋。

## 專案檔案

- `index.html`：GitHub Pages 首頁（與下列單檔相同）
- `生物科財產工作站.html`：可直接使用的單檔離線程式
- `release/生物科財產工作站_完整套件.zip`：完整套件下載檔
- `src/`：來源碼與建置器
- `115年度清冊資料.json`：預載資料
- `tests/`：資料、邏輯與瀏覽器驗證
- `vendor/PDFjs-LICENSE.txt`：PDF.js 授權
- `使用說明.md`：手機與桌面使用說明

## 開發

```sh
npm ci
npm run build -- --source-dir ../115財產
# 建置器會同步產生 GitHub Pages 用的 index.html
npm test
```

原始 PDF 以 base64 內嵌於單檔 HTML；任何更新年度資料前，請核對 PDF、頁碼、筆數及唯一識別碼。
